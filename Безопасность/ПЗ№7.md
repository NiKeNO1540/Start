### 1. Цель работы
Освоение навыков настройки базовых механизмов безопасности на коммутаторах Cisco (L2 Security) для защиты сетевой инфраструктуры от атак канального уровня, таких как MAC-flooding, подмена DHCP-сервера и ARP-spoofing.

### 2. Схема сети и описание стенда
Для выполнения работы использовалась следующая логическая топология (на примере Cisco Packet Tracer):
*   **Коммутатор (Switch):** Cisco 2960.
*   **Маршрутизатор (Router):** Выступает в роли легитимного DHCP-сервера. Подключен к порту `Gi0/1`.
*   **Клиент (PC1):** Легитимный пользователь. Подключен к порту `Fa0/1`.
*   **Атакующий (PC2):** Устройство для проверки защиты. Подключено к порту `Fa0/2`.

Все устройства находятся в **VLAN 1**.

---

### 3. Выполнение практических заданий

#### Задание 1. Настройка Port Security
**Цель:** Ограничить количество MAC-адресов на порту пользователя, чтобы предотвратить атаку переполнения таблицы коммутации (MAC-flooding) и подключение несанкционированных коммутаторов.

**Конфигурация (интерфейс Fa0/1):**
```cisco
Switch> enable
Switch# configure terminal
Switch(config)# interface fa0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport port-security
Switch(config-if)# switchport port-security maximum 2
Switch(config-if)# switchport port-security violation restrict
Switch(config-if)# switchport port-security mac-address sticky
Switch(config-if)# switchport port-security aging time 15
Switch(config-if)# exit
```
*Пояснение:* Порт переведен в режим доступа (обязательно для Port Security). Максимум 2 MAC-адреса. При нарушении (появлении 3-го адреса) порт не выключается, но блокирует пакеты и шлет уведомление (`restrict`). Адреса запоминаются автоматически (`sticky`).

#### Задание 2. Настройка DHCP Snooping
**Цель:** Защита от поддельных DHCP-серверов (Rogue DHCP). Порт маршрутизатора назначается доверенным, остальные — недоверенными.

**Конфигурация:**
```cisco
Switch(config)# ip dhcp snooping
Switch(config)# ip dhcp snooping vlan 1
Switch(config)# interface gi0/1
Switch(config-if)# description UPLINK_TO_ROUTER
Switch(config-if)# ip dhcp snooping trust
Switch(config-if)# exit
```
*Пояснение:* Включен глобальный мониторинг DHCP. Порт `Gi0/1`, куда подключен реальный DHCP-сервер, объявлен доверенным (trust). Порты пользователей `Fa0/1` и `Fa0/2` остались в статусе `untrusted` (по умолчанию).

#### Задание 3. Настройка Dynamic ARP Inspection (DAI)
**Цель:** Защита от ARP-spoofing (атак типа «Человек посередине»). Коммутатор проверяет соответствие IP и MAC адресов в ARP-пакетах на основе базы данных DHCP Snooping.

**Конфигурация:**
```cisco
Switch(config)# ip arp inspection vlan 1
Switch(config)# interface gi0/1
Switch(config-if)# ip arp inspection trust
Switch(config-if)# exit
```
*Пояснение:* Включена инспекция ARP для VLAN 1. Аплинк `Gi0/1` настроен как доверенный (проверка ARP не производится), пользовательские порты проверяются строго.

### 5. Ответы на контрольные вопросы

**1. Какие типы нарушений (violation modes) Port Security существуют?**
*   **Shutdown (по умолчанию):** Порт отключается (переходит в состояние err-disable), отправляется SNMP trap и сообщение в syslog.
*   **Restrict:** Пакеты с неизвестных MAC отбрасываются, счетчик нарушений растет, отправляется SNMP trap/syslog. Порт остается включенным.
*   **Protect:** Пакеты отбрасываются, но уведомления не отправляются и счетчик не растет.

**2. Для чего нужен DHCP Snooping?**
Он предотвращает подключение несанкционированных (Rogue) DHCP-серверов, которые могут выдать клиентам неверные настройки шлюза или DNS для перехвата трафика. Также он создает базу данных привязок (Binding Database), необходимую для работы других защитных механизмов (DAI, IP Source Guard).

**3. Как работает Dynamic ARP Inspection (DAI)?**
DAI перехватывает все ARP-запросы и ответы на недоверенных портах. Он сверяет пару IP-MAC внутри ARP-пакета с записью в базе данных DHCP Snooping Binding. Если соответствия нет, пакет отбрасывается, предотвращая отравление ARP-кэша.

**4. В чем преимущество использования IP Source Guard?**
IP Source Guard работает на уровне IP (L3) фильтрации на портах коммутатора. Он предотвращает IP-спуфинг (подмену IP-адреса отправителя), позволяя пропускать трафик только с того IP-адреса, который был выдан этому порту по DHCP.

**5. Какие действия можно настроить при нарушении Port Security?**
Можно настроить полное отключение порта (shutdown) для максимальной безопасности, либо ограничение трафика только от разрешенных MAC-адресов (restrict/protect) для обеспечения доступности сервиса для легитимных пользователей.

В ходе практического занятия была произведена настройка комплексной защиты коммутатора на канальном уровне (L2).
1.  **Port Security** позволил ограничить доступ к порту конкретными физическими устройствами.
2.  **DHCP Snooping** разделил сеть на доверенную зону (серверы) и пользовательскую зону, предотвратив возможность внедрения ложного DHCP-сервера.
