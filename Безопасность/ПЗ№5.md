### 5. Ответы на контрольные вопросы

**1. Какие типы правил существуют в брандмауэре?**
Существуют правила для входящих подключений (Inbound), правила для исходящих подключений (Outbound) и правила безопасности подключения (IPSec). Внутри этих категорий правила делятся на:
*   Для программы (Program).
*   Для порта (Port).
*   Предопределенные (Predefined) — для системных служб.
*   Настраиваемые (Custom) — сложные правила с выбором протоколов и интерфейсов.

**2. Как настроить временные правила доступа?**
В стандартном GUI Windows Firewall нет настройки времени действия. Это реализуется через:
*   Групповые политики (GPO).
*   Скрипты PowerShell в Планировщике задач (включение/отключение правила по расписанию).
*   Сторонние надстройки или использование шлюзовых решений (например, ISA/TMG, iptables в Linux).

**3. В чем разница между входящими и исходящими правилами?**
*   **Входящие (Inbound):** Фильтруют трафик, инициированный извне к нашему компьютеру (актуально для серверов). Если правила нет, трафик блокируется по умолчанию.
*   **Исходящие (Outbound):** Фильтруют трафик, который наш компьютер пытается отправить в сеть. По умолчанию в Windows исходящий трафик разрешен, если не создано запрещающее правило.

**4. Как экспортировать/импортировать настройки брандмауэра?**
В консоли «Брандмауэр Windows в режиме повышенной безопасности»:
*   В правой панели «Действия» выбрать пункт **Экспорт политики**. Файл сохраняется в формате `.wfw`.
*   Для восстановления выбрать пункт **Импорт политики** и указать файл.

**5. Какие порты необходимо открыть для основных сервисов?**
*   Web (HTTP/HTTPS): TCP 80, 443.
*   Удаленный доступ (RDP): TCP 3389.
*   DNS: UDP/TCP 53.
*   SSH (для Linux): TCP 22.
*   Почта (SMTP/IMAP): TCP 25, 587, 143, 993.
